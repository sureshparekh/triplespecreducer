# Citing

The algorithms are Spextool's. As the TS4_SOAR README asks, refer to the reduction as done with
"a modified version of Spextool" and cite:

* **Spextool** — Cushing, M. C., Vacca, W. D., & Rayner, J. T. 2004, PASP, 116, 362
* **Telluric correction** — Vacca, W. D., Cushing, M. C., & Rayner, J. T. 2003, PASP, 115, 389
* **The TripleSpec modifications** — Kirkpatrick, J. D., et al. 2011, ApJS, 197, 19 (§4.4)

and this program (TripleSpec Reducer, Parekh 2026). Every source of the method, with what each
supports, is on [Sources](sources.md).

The reduction workflow and its choices follow the SOAR TripleSpec data-reduction tutorial by
Luis G. Dahmer-Hahn. The interface uses the design of BRAIN.
