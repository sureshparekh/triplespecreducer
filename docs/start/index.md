# Get started

TripleSpec Reducer reduces near-infrared spectra from the SOAR TripleSpec 4.1 spectrograph,
from the raw frames to a flux-calibrated, telluric-corrected spectrum. It is a desktop
application first: it reads a night's headers, proposes the reduction plan, and walks through
the seven steps of the reduction, each explained as it runs.
